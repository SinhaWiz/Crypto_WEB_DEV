# Educational Crypto Trading Simulator

An educational crypto trading simulator built with a raw React frontend and an Express + MongoDB backend.

## Stack

- Frontend: React
- Backend: Express
- Database: MongoDB
- Real-time updates: Socket.io

## Product Rules

- This project is educational only.
- No real cryptocurrency trading will ever occur.
- No real-money deposits, withdrawals, bets, or payouts are supported.
- All balances, trades, price changes, and rewards are virtual.

## Core Features

- User registration and login
- Protected dashboard and profile pages
- Virtual wallet seeded with 100,000 BDT
- Multi-asset market view with simulated pricing
- Buy and sell trading flow
- Portfolio and transaction history
- Prediction challenges using virtual points
- Leaderboard, achievements, and learning content
